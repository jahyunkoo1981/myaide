MY AIDE 개인정보처리방침

시행일 2026년 11월 28일

MY AIDE는 사용자가 자신의 업무 기록을 자신의 Google Drive에 저장하고 여러 기기에서 이어 쓰도록 돕는 개인용 업무 비서 프로그램입니다. MY AIDE에는 별도의 운영 서버가 없으며, 개발자는 사용자의 기록을 수집하거나 보관하지 않습니다.

1. 사용하는 Google 데이터

  • MY AIDE는 Google Drive의 drive.file 권한만 요청합니다. 이 권한으로는 MY AIDE가 직접 만든 파일만 읽고 쓸 수 있으며, 사용자의 다른 Drive 파일은 볼 수 없습니다.
  • 로그인한 Google 계정의 이메일 주소(openid, email 권한)를 확인합니다. 관리자가 승인한 사용자인지 확인하는 데에만 쓰이며, 사용자의 기기 안에만 저장되고 다른 곳으로 보내지 않습니다.
  • 기록(업무일지, 메모, 일정, 가계부, 회의록 등)은 사용자 본인의 Google Drive 안 MY AIDE 폴더에 저장됩니다.

2. 데이터 저장 위치

  • 사용자의 기기(브라우저 저장소 또는 Windows 앱 데이터 폴더)와 사용자 본인의 Google Drive에만 저장됩니다.
  • 계정정보와 API 키는 사용자가 정한 금고 암호로 기기에서 암호화된 뒤 저장되며, 개발자나 Google도 내용을 읽을 수 없습니다.

3. 제3자 제공

  • MY AIDE는 사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다.
  • 사용자가 AI 기능(OpenAI)을 직접 켜고 본인의 API 키를 입력한 경우에 한해, 사용자가 요청한 내용이 사용자 기기에서 OpenAI로 직접 전송됩니다.

4. 데이터 삭제

  • Google Drive의 MY AIDE 폴더를 삭제하면 저장된 기록이 모두 지워집니다.
  • Google 계정 설정의 ‘타사 앱 및 서비스’에서 MY AIDE의 접근 권한을 언제든 해제할 수 있습니다.
  • MY AIDE 설정 화면의 ‘이 기기에서 데이터 지우기’로 기기에 남은 데이터를 지울 수 있습니다.
