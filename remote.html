연결 준비 중…
상대가 마우스·키보드를 직접 조작해야 하나요?
  1. 아래 원격지원 도우미 받기를 눌러 내려받습니다 (16KB, 설치 없음).
  2. 받은 파일을 실행합니다. Windows 경고가 뜨면 추가 정보 → 실행을 누릅니다.
  3. 이 페이지로 돌아오면 자동으로 연결됩니다. 브라우저가 ‘로컬 네트워크 접근’을 물으면 허용을 누르세요.
원격지원 도우미 받기
도우미 창을 닫거나 ‘제어 끝내기’를 누르면 즉시 조작이 끝납니다. 도우미는 개인 정보를 저장하지 않습니다.
